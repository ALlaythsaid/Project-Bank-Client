## 🚀 Key Features
- **Authentication & Authorization:** Bitwise permission flags for user screens.
- **Client Management (CRUD):** Full management of bank clients and records.
- **Transactions Engine:** Deposit, Withdraw (with balance checks), and Transfers.
- **Audit Logging:** Comprehensive Transfer Log history with timestamps.
- **Currency Exchange Engine:** Live conversion calculations and currency database.
